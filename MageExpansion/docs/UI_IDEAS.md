## 1. Сравнение с надетой вещью — разведка
- `GUI\Win32\tooltip.gfx` уже умеет вторую рамку: `setTitles(item, comparableItem)`, `setItemName(sName, isDescription,
  comparableItem)`, `setTooltipText(tooltip, comparableItem)`; при `comparableItem = true` текст идёт во вторую рамку.
- exe заполняет обе рамки: функция около `0xAA2800…0xAA3260` (вызовы `setTitles`/`setItemName`/`setTooltipText`, второй

- Вход: `0xAA27A0` — обработчик событий окна, работает только для событий 0xC/0xD; вызывается из `0xA4443E` и
  `0xB2525E`. TODO: какие это окна и почему в инвентаре/у сундука сравнения нет.

## Лестницы (ошибка оригинальной игры) — исправлено, проверено 08.11
Поворот камеры на лестнице уводил героя в воздух. Тактика `LadderAvatarControl` (vtable `0x1330410`, обновление — слот 5
`0x920C80`, раз в кадр). Div2Fix `[Fixes] LadderCameraLock=1`: пока слот 5 вызывается (окно 150 мс), горизонтальное
движение мыши (DIMOFS_X) в `GetDeviceData` обнуляется. Трассировка слотов: `[Diagnostics] LadderTrace=1`.

## Подсветка разницы в сравнении — проверено 08.11
Div2Fix `uinav.c`, `tip_compare`, `[UI] CompareColors=1`. Текст выбранной вещи: `setTooltipText(text)` (один аргумент), надетой:
`setTooltipText(text, true)`; UTF-16 HTML, строки через `\n`. Значения с одинаковым названием складываются, красятся только
характеристики, которые есть у обеих вещей. Покрашенный текст отправляется ДО текста надетой: ложный `comparableItem`
скрывает вторую рамку. Строки с другим названием (талисманы, «увеличивает … на N») не сравниваются.
Перед релизом убрать: `tip_trace`, отладочную строку `UI: compare:`.
