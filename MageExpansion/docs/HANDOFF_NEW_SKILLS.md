## Сборка и установка (PowerShell, из `MageExpansion`)
```
$G='C:\Program Files (x86)\Steam\steamapps\common\divinity2_dev_cut'
$env:PATH="C:\Program Files\LLVM\bin;"+$env:PATH
& ..\native\div2fix\build.cmd
py -3 -I tools\build_mage.py $G build
py -3 -I tests\check_archive.py $G build\MageExpansion.dv2
Copy-Item ..\native\div2fix\build\dinput8.dll "$G\bin\dinput8.dll" -Force
cmd /c install\install.cmd
```
- После каждого шага проверять `$LASTEXITCODE`: скрытая ошибка однажды привела к установке старого архива.
- Перед установкой проверить `Get-Process Divinity2`.
- `Div2Fix.ini` игры править как байты (CRLF, не UTF-8). Правки лежат только в игровом ini.
- Bash-heredoc портит обратные слэши и апострофы: скрипты правок писать отдельным файлом.

## Где что лежит
- `native/div2fix/src/mageskills.c`: вся логика навыков. `hk_takeHit` (детур 0x76C800) меняет урон, `own_cast` (детур 0x923FC0) ловит каст, `own_tick` работает каждый кадр.
- `MageExpansion/config/skills.json`: навыки, ранги, тексты RU/EN, клетка `tree` (`[ряд, столбец]`).
- `MageExpansion/tools/`: `build_mage.py`, эффекты `fx_chain.py` и `fx_icebolt.py`, иконки `icon_art.py` (список имён в цикле около строки 1114), звуки `sfx_*.py`.
- `MageExpansion/assets/icons/*.png`: иконки пользователя. `assets/sounds/`: звуки и README с лицензиями.

## Как добавить навык
1. Запись в `config/skills.json`, плюс имя иконки в `icon_art.py`.
2. В игровой `Div2Fix.ini`, секция `[MageSkills]`: id в `Grant=`, `Name<id>=`, `Trainer<id>=`, свой ключ навыка.
3. Новый эффект: класс в `fx_chain.py` (нужны `SOURCE, DURATION, BOUND, textures, build`) и имя в словаре `mod` в `build_mage.py`.
4. Новый звук: строка записи в `build_mage.py` и строка `copy` в `install/install.cmd`.

## Полезные факты о движке
- Удар (hit): float `[0..3]` по типам урона, магия в `[2]`. `+10` крит (любое ненулевое значение, бывает 1 и 2), `+14` тип (1 ближний, 3 стрела, 4 периодический, 5 магия), `+18` handle атакующего, `+20` (5 = без отражения).
- `0x75BDE0` параметр навыка по (id, индекс), индекс 0 = Param1. `0x763AD0` есть ли навык. `0x759820` thiscall(stats): не 0 = женский персонаж.
- Призванные: список в `[[stats+FC]+54..58]` шагом 8 байт, существо Хрустального черепа отдельно (см. `hunger_after_hit`).
- Цели вокруг: таблица статов менеджера, см. `own_targets` и `cry_catch`.
- `status_puff` запускает свободный эффект, за персонажем он не следует.
- Код Ядовитых стрел: **Param1 и Param2 навыка должны быть 0**, иначе на врага ложится яд. Свои числа хранить с Param3.
- Выстрел: `0x748520` thiscall(x, y, z), вызывается из **пяти** мест: 0x74A47B, 0x74A799, 0x74A8C9, 0x74AA8E, 0x74AD37.
- `MAX_GRANT` поднят до 32 (при 16 семнадцатый навык молча не выдавался).
- Звуки игры (Wwise): General_Sounds.bnk вызывается по имени (`OwnCastSound`, например `Skill_Fireball_Cast`). Голоса в HumanFemale/HumanMale.bnk: имён событий нет, данные в Wwise Vorbis, не извлечены.
