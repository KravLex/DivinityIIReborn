# Наши навыки на случайных вещах: разведка 07.11.2026

## Как это устроено в игре
`Episodes\Episode_1_Extended\rpgstats_itemmagicaleffects.xml` и такой же `Episode_2\...` (MainDataStartup.dv2,
бинарный XML, 28377 байт). Группы свойств: `Primary Stats`, …, **`Skill Boosters`** — 47 записей «+N к навыку»,
по одной на навык игры. Пример:

`<effect Name-hash="Fireball" min="1" max="60" weight="3" prefix="Burning" a="1" b="1" value="700" class="M" id="239">`

| Атрибут (хеш) | Значение (по данным) |
|---|---|
| `H_0006810C` | имя навыка (как в `rpgstats_skillprototypes.xml`) |
| `H_BB46E9F2` / `H_BABBA1B4` | уровень вещи от / до (1…60) |
| `H_7E271012` | вес выпадения (у навыков 3, у характеристик 100) |
| `H_C2E4BDEE` | приставка к имени вещи («Burning», «Stormy»…) |
| `H_AC57C8D1`, `H_4C0F8153` | величина бонуса (у навыков 1 и 1) — TODO: какая из них «+N» |
| `H_282F6C23` | добавка к цене (700…4500) |
| `H_7A512C4C` | класс вещей: W воин, M маг, D некромант, R следопыт |
| `H_00017342` | уникальный номер свойства (навыки 239…285) |

В exe строка `Skill Boosters` используется в коде предметов (`0x8DAF08`, `0x8DC86F`, `0x8DCFDF`, `0x8DD23D`): бонус к навыку
обрабатывается отдельно.

## Вывод
Добавить наши навыки можно данными, без правки exe: сборка кладёт в overlay копию этого файла (оба эпизода) с новыми
записями в `Skill Boosters` (номера с 286), приставки получают перевод в локализации.

## Риски (проверить до выпуска)
1. **Сохранения.** Вещь в сохранении, скорее всего, хранит номер свойства. Если потом удалить мод, вещь с номером 286+
   может сломать загрузку. Проверить на копии сохранения.
2. **Ранги выше предела.** Бонус «+1» к навыку на 5 ранге у Сыщика/Красноречия (5 рангов) даст 6-й ранг, которого нет в
   прототипе. Такие навыки не добавлять, пока не проверено, что игра ограничивает ранг.
3. Как игра находит навык по имени (`0x8DAF08`…): если по таблице прототипов, наши навыки найдутся (они там
   зарегистрированы, `prototype id … registered`). Проверить первым тестом.
4. Описание вещи: строка «+1 к …» берёт имя навыка из локализации — у наших навыков русские имена есть.

## Откуда бонус к навыку берётся на вещи (08.11, по коду exe)
Бонусы к навыкам выпадают не в обычные слоты, а в свои: `rpgstats_uniqueness.xml` задаёт по редкости слоты 1–4 с типами
`N/L/M/B/QL/QM/QH/J/K`. Код `0x8DCF67…0x8DD0A6` набирает для слота взвешенный (`Frequency`) список **только** из
группы `Skill Boosters`, фильтр — `0x7E4900` по `AllowUse`: буквы `X/Y/Z/A/B` сверяются с `MagicEffectCategory` вещи,
`J` (украшения) — с классом `W/R/D/M`. Слот B есть у редкостей Magical (1B), Heroic (2B, 3B), Legendary (4B); слот J —
у украшений с Uncommon. До правки у брони/оружия слот B оставался пустым: ни один бонус к навыку не разрешал A/X/Y/Z.
Итог: на броне и оружии бонусы к навыкам появятся только на новых вещах редкости Magical и выше.

## Причина «только украшения» и исправление (08.11, по трассировке и коду)
Трассировка (`[Diagnostics] BoosterTrace=1`): все бонусы к навыкам доставались вещам категории `J`. Функция `0x8DC900`
для украшений берёт свойства с `BaseType == "Skill Boosters"` (`operator==`), для остальных — `!= "Skill Boosters"`
(`0x8DD24E: call [operator!=]`). Div2Fix `[SkillBoosters] Everywhere=1` заменяет этот вызов на `mov al,1` (сверка байтов,
адрес импорта с поправкой на сдвиг образа). Броня и оружие берут характеристики и бонусы к навыкам по `Frequency`; веса
под ~20 %: база +1 = 2 (`base_freq`), ступени 1/1 → броня 19–36 %, молоты 12–24 %, мечи/топоры/луки 6–14 % по уровню.

Проверено в игре 08.11: бонусы к навыкам видны в подсказках брони и оружия. BoosterTrace выключен в игровом ini; код трассировки убрать перед релизом.
