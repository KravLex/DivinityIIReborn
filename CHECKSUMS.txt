All files with hashes: see the release notes / DivinityIIReborn_v1.5_SHA256.txt.

Reproducing dinput8.dll: building div2fix/ with LLVM (build.sh or build.cmd) gives a file that is
byte-identical to the released one except the 4-byte PE TimeDateStamp at file offset 0x80 (same LLVM version).
*.dxso and the SMAA lookup textures: tools/shaders/ rebuilds them byte for byte (with the system d3dcompiler_47).
d3d9.dll: a GCC/MinGW build is not bit-reproducible across toolchains; compare behaviour, or use the official
DXVK 3.1.1 x32/d3d9.dll instead (see README).
